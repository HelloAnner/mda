# 看板源码工作流

本 Skill 只约束工程质量和安全边界，不约束页面表现。你可以自由创建、删除、拆分和重构 `src/**` 与 `public/**`，也可以使用当前工程允许的 HTML、CSS、React、SVG、Canvas、WebGL 或浏览器能力。

## 开始前

1. 检查当前 Session 工作区、已有源码、清单和可用脚本；延续已有实现，不要无故重建。
2. 同时读取 `dashboard-foundations` 与 `dashboard-data-communication`。再根据任务最多选择一个主要呈现 Skill 和一个主要行业 Skill；无明确匹配时不要硬套主题。
3. 从用户目标、数据摘要和现有页面推断受众、决策、时间范围与设备。只有缺失信息会阻碍安全或真实实现时才追问，否则采用克制且可逆的默认方案。

## 实现边界

- 所有文件操作只发生在当前 Session 工作区。
- 数据源摘要仅用于只读理解；不得创建、修改、删除、测试、启停或配置数据源，不得索取、读取或输出凭据。
- 只使用当前模板已经批准的依赖。不得修改平台拥有的依赖和构建边界，不得用安装新包来回避简单实现。
- 不得为了迎合 Skill 而发明不存在的数据、查询、刷新、预览或发布能力。
- Skill 给出的是判断依据，不是组件目录。不要把任何示例变成强制组件、固定网格或 JSON UI Schema。

## 工作循环

1. 先理解页面要帮助谁看懂什么、作出什么决定。
2. 检查数据字段、单位、时间、空值和限制，再组织信息。
3. 直接编辑真实源码；保持语义清晰、响应式、键盘可用。
4. 完整处理加载、空、部分、刷新、陈旧、错误、无权限和正常状态。
5. 使用工作区已有命令验证类型、构建和关键交互；检查窄屏和长文本，不只检查理想数据。
6. 根据错误继续修复，直到验证通过或出现无法在当前边界内解决的阻塞。

## 完成报告

简洁说明改了什么、验证了什么、仍有哪些真实限制。只有相应 Tool 确实成功后，才能声称已构建、预览、发布或接入实时数据。

当前尚未提供数据源与发布 Tool。需要数据时使用明确标注的模拟数据或诚实空状态，并说明实时接入仍待完成。
