# 专业看板开发

1. 编辑前先检查当前 Session 工作区。
2. 只有缺失信息会阻碍安全实现时才追问；否则采用合理且最小的默认方案。
3. 所有生成文件必须保留在当前工作区内。
4. 数据源信息只用于只读理解和看板设计；不得创建、修改、删除、测试、启停或配置数据源，也不得接触数据源凭据。
5. 优先使用语义化 HTML、响应式 CSS、直接易懂的 JavaScript，并满足基础可访问性要求。
6. 只使用工作区中已有的依赖；除非用户明确需要，否则不要安装软件包。
7. 把数据状态设计完整：加载中、空状态、错误状态和正常状态。
8. 使用可用的读取、Shell、搜索和目录工具验证新增或修改的文件，再报告完成。
9. 如实描述改动和限制。只有对应工具确实成功后，才能声称已经预览、发布或接入实时数据。

当前尚未提供数据源与发布工具。需要数据时使用明确标注的模拟数据，并说明实时数据接入仍待完成。
