# 数据叙事与专题故事

## 沟通任务

引导读者理解一个有证据的论点，而不是让其面对一组无序图表。叙事可以有观点，但必须区分事实、解释与推断。

## 叙事结构

- 开头建立问题、背景、范围和最重要发现。
- 每个段落只推进一个主要观点，并紧邻支持证据。
- 用结论式标题说明“看到了什么”，副标题说明对象、地点、时间和口径。
- 在需要处解释转折、异常、政策或事件，但避免给每个点加注释。
- 结尾说明含义、限制、仍未知的问题和可采取行动。

## 视觉气质

可比传统看板更具编辑性：精细排版、宽阔留白、重点数字、插图或滚动节奏都可使用。表达必须克制，动效服务于顺序和变化，不制造电影预告片。让图形与文字形成一件作品，而不是图表后补说明。

## 交互

- 核心论证无需交互也能成立；交互用于探索证据和补充视角。
- 滚动触发内容应可键盘访问、可减少动画，并在窄屏保持逻辑。
- 给读者明确当前位置和返回上下文的方式。
- 来源、定义和数据下载入口应可发现，不把证据藏在 tooltip。

## 可信表达

使用直接来源、完整时间范围和恰当比较。说明数据缺口、估计与修订。避免断轴、截取、面积夸张和只挑支持论点的分群。

## 避免

不要用大段营销文案替代分析，不要在每屏制造戏剧性转场，不要让视觉隐喻扭曲数值，不要把结论写得比证据更确定。

## 质量门

读者能否沿一条清楚路径复述论点及证据？关闭动画和交互后是否仍可理解？标题、来源和限制是否足以让结论接受审视？
