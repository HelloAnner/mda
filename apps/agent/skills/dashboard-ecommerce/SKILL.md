# 电商经营看板 Know-how

## 核心决定

帮助经营者判断增长是否健康、转化哪里流失、客户价值是否覆盖获客成本、商品与库存是否支撑履约、退货为何侵蚀利润。

## 指标关系

- 需求：流量、来源、新老访客和高意向会话，过滤机器人和内部流量。
- 转化：浏览、加购、结账、支付和订单；明确会话/用户分母、去重与窗口。
- 价值：订单、GMV/收入、折扣、客单、毛利与净收入，避免只看 GMV。
- 客户：新客、复购、队列留存、CLV 与 CAC；预测价值标明模型与成熟度。
- 商品：销量、毛利、转化、库存、缺货和组合贡献。
- 履约与退货：承诺、发货、送达、取消、退款、退货原因和恢复价值。

Shopify 等行业实践常将转化、客单、获客成本、复购、库存和退货共同观察；这些指标应作为系统而不是独立卡片。

## 视觉与交互

从业务结果进入旅程、商品与客户结构。促销和季节事件要标注，比较使用可比星期、节假日和活动周期。筛选渠道时同步更新花费、转化和价值口径。

## 状态

最近订单可能取消或退货，收入可能回填；标明成熟窗口。支付失败、追踪缺失、库存同步延迟和未归因必须可见。

## 避免

不要以流量增长代替经营增长，不把购物车放弃公式写错，不用高 ROAS 掩盖低毛利，不忽略退货和折扣对客户价值的影响。

## 质量门

用户能否从获客一路追到毛利、复购、履约和退货，并理解窗口、去重、成熟度和活动效应？
