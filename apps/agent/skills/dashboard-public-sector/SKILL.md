# 公共部门与统计发布看板 Know-how

## 核心决定

面向公众、政策人员或服务运营者时，分别明确理解、问责、资源配置或服务改进目标。公共看板应优先可解释、可访问、可复核，而不是机构宣传。

## 信息要求

- 清楚说明统计对象、地域、时间、单位、来源、发布日期和下一次更新。
- 指标定义、方法、修订、季节调整和边界变化应可发现。
- 同时考虑总量、率、人口分母和群体差异；地域比较需注意规模与结构。
- 政策投入、活动、产出、结果和长期影响不要混成一条因果链。
- 目标进展应显示基线、目标年、当前路径和数据延迟。

## 数据表达

使用结论式标题与正式统计副标题。图形需要清楚标签和文本摘要；重要数据提供可访问表格或下载（平台能力存在时）。地图只在地域模式有意义时使用，并说明分级方法与缺失区域。

## 可访问与信任

满足键盘、重排、对比和非颜色编码。避免只在图片内放标题或来源。公众看板应解释“暂无数据”“未上报”“不适用”和“抑制”区别，敏感小样本按政策处理。

## 视觉气质

中立、清楚、有公共信任感。品牌可存在但不能压过证据。避免庆功式插画、过度圆润、政治化颜色和只展示有利指标。

## 避免

不要把排名当问责全部，不用绝对数量比较人口差异地区，不把相关政策与结果写成已证实因果，不静默替换历史数据。

## 质量门

普通公众能否理解主要结论，专业人员能否找到定义与来源，辅助技术用户能否获得等价信息？限制和修订是否与成果同样可见？
