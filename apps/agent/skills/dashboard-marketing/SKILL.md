# 市场与增长看板 Know-how

## 核心决定

回答增长来自哪里、投入是否有效、哪一段旅程流失、哪些结果只是归因模型产物。先明确目标是品牌、需求生成、获客、激活、收入还是留存。

## 指标体系

- 触达与质量：曝光、覆盖、频次、可见性和目标受众匹配。
- 参与：访问、内容消费、互动与高意向行为，避免只看虚荣流量。
- 转化：从合格起点到目标行为的分阶段转化，明确去重和窗口。
- 效率：花费、CPA/CAC、ROAS、边际成本与预算消耗。
- 下游价值：激活、收入、毛利、复购或留存；不要停在点击。
- 结构：渠道、活动、创意、受众、地区、设备和新老用户。

## 归因与实验

标明归因模型、窗口、跨设备限制和数据延迟。归因贡献不等于增量效果；有实验时区分对照、提升和不确定性。渠道之间不可在口径不同的转化上直接排名。

## 视觉与交互

从业务结果向上游驱动展开，显示花费与结果的共同变化。时间趋势要标注活动和预算变化，但避免将同步变化写成因果。筛选应保持漏斗同群体与同周期。

## 状态

处理隐私阈值、追踪缺失、平台回填、未归因和转换延迟。最近日期可能未成熟，不能与完整历史直接比较。

## 避免

不要用彩色渠道卡堆虚荣指标，不只展示最好创意，不把 ROAS 脱离毛利和增量，不隐藏无归因份额。

## 质量门

用户能否从投入追到下游价值，并理解归因、窗口、时滞和数据缺口？
