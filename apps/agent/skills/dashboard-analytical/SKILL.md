# 分析探索看板

## 决策任务

让熟悉业务的用户从概况进入证据，比较分群、定位驱动、检查异常并保留分析上下文。探索自由不能以口径不透明为代价。

## 信息组织

- 先说明分析问题、样本范围、时间与当前筛选，再展示主要模式。
- 概览、分布、关系、分段和明细形成递进，不把所有维度同时暴露。
- 关键指标可拆解到有业务含义的维度；保留从聚合返回整体的路径。
- 明细支持验证聚合结论，但敏感字段和高基数维度要克制。
- 对比视图保持同口径、同尺度和稳定排序。

## 视觉气质

理性、清晰、数据密度适中。允许更多轴、图例和控制，但用空间与分组控制复杂度。强调直接标签、参考线、注释和小倍图式一致比较；不为了“分析感”铺满细网格。

## 交互

- 筛选器显示作用域、默认值和清除方式；相关筛选不要形成无法理解的隐式联动。
- 选择一个标记时，明确其他区域是过滤、高亮还是比较。
- 提供稳定链接或摘要，使当前分析状态可以复现和分享（能力存在时）。
- 对代价高的查询给出进度、范围与取消反馈。

## 分析纪律

相关不是因果；分段结果可能受样本量、幸存偏差和口径变化影响。显示必要的分母、置信或质量说明。避免只展示平均值；在结论依赖分布时给出离散与极值。

## 避免

不要提供几十个无层级筛选器、自动联动到用户无法解释、默认截取有利时间段、用双轴暗示关系、把下载原始数据当成唯一明细体验。

## 质量门

用户能否解释当前视图如何得到、比较口径是否一致、如何回到整体、哪些结论只是相关？若探索过程不可复现或筛选上下文会丢失，应修正。
