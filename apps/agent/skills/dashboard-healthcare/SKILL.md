# 医疗与照护看板 Know-how

## 边界

看板用于运营、质量改进和证据沟通，不替代临床判断、诊断或治疗建议。最小化患者可识别信息，并尊重角色权限。

## 核心决定

根据场景区分质量与安全、容量与流量、流程依从、患者结果或公共卫生。AHRQ 等质量框架提示应将指标用于识别改进机会，而不是脱离背景评价机构或人员。

## 指标关系

- 结果与安全：事件率、并发症、再入院、死亡或伤害必须有明确分母、时间窗与排除规则。
- 流程：等待、周转、依从、转诊和护理路径；速度不能压过安全与质量。
- 容量：床位、人员、队列、占用和预计需求；区分可用、配备与物理容量。
- 体验与公平：满意、投诉和人群差异；显示样本与回应偏差。
- 公共卫生：病例、率、覆盖与趋势；考虑报告延迟和修订。

## 解释纪律

标明风险调整、标准化、置信区间、小样本抑制和基准群体。绝对人数与比率在安全场景常需并列。数据编码、定义或上报变化可能造成假趋势。

## 视觉与状态

安静、可信、非恐吓。安全异常明确但不使用满屏警报色。未知、待确认、延迟上报和已修订必须可区分。敏感明细不得通过 tooltip 或导出意外暴露。

## 避免

不要做无风险调整的粗暴排名，不把相关当疗效，不用平均等待掩盖高危长尾，不把缺失病例显示为零。

## 质量门

分母、时间窗、风险调整、数据延迟和隐私是否足以让专业人员正确解释？页面是否帮助改进而非制造不公正归因？
