# 看板设计基础

目标不是让页面“像一个仪表盘”，而是让它成为一件清晰、可信、现代、禁得起凝视的信息作品。你拥有完整的组件与源码自由；以下规则只定义质量，不定义实现。

## 1. 先建立阅读任务

动手前明确：

- **受众**：谁在看，专业程度如何，是否共享屏幕或移动使用。
- **决定**：看完后要判断、比较、调查或采取什么行动。
- **时效**：实时处置、每日跟踪、周期复盘还是长期叙事。
- **主问题**：页面第一屏必须回答的一个问题。
- **证据层级**：结论、驱动因素、异常、细节分别需要多少空间。

不要把所有字段平铺为同等大小的卡片。先形成一句页面命题，再让每个区块服务于它。

## 2. 视觉层级

- 第一视觉锚点承载最重要的判断，不一定是最大数字，也可以是变化、风险、异常或一句结论。
- 从概览到解释再到细节形成自然阅读顺序；相邻信息应有真实关系。
- 用留白、位置、尺寸、字重和对比建立层级，少依赖边框和容器堆叠。
- 同类元素严格对齐并复用节奏；不同层级必须看得出重量差。
- 将筛选、单位、时间范围和数据新鲜度放在能解释当前视图的位置，而不是藏在角落。

## 3. 现代审美

- 先做好比例、排版、间距和对齐，再考虑材质效果。
- 使用克制的中性色建立大面积背景，只留少量语义色与焦点色。
- 字体层级少而明确；数字使用适合比较的字形与对齐，标题避免营销式空话。
- 描边、阴影、圆角、玻璃和渐变必须有结构作用。避免厚重阴影、巨大圆角、霓虹泛光、装饰性渐变和满屏悬浮卡片。
- 图标只帮助识别或操作，不替代标签；装饰插画不得压过数据。
- 精致来自细节一致：基线、数字格式、状态间距、焦点环、截断和响应式都应经过处理。

## 4. 响应式与密度

- 先按真实使用尺寸设计，再验证宽屏、普通桌面、平板和窄屏。
- 窄屏应重新编排优先级，而不是机械缩小桌面版；关键结论先出现，次要细节可按需展开。
- 避免整页横向滚动。确需横向比较的局部区域应有明确边界和操作提示。
- 长名称、极值、空值、多语言和高密度数据不能破坏布局。
- 触控目标、悬停信息和键盘路径都要可用；不要让关键事实只存在于 hover。

## 5. 交互

- 直接操作优于控制面板堆叠。筛选、选择、钻取和重置应贴近其影响范围。
- 每次交互都要让用户看见范围、结果与撤销路径。
- 保持筛选上下文：当前条件、比较基线和时间范围始终清楚。
- 动画只解释变化、层级或因果，不用于制造“高级感”。尊重减少动态效果偏好。
- 不用自动轮播隐藏关键信息，不让实时刷新抢走焦点或重置用户操作。

## 6. 完整状态

每个依赖数据的区域都考虑：

- **加载**：保留结构，说明正在发生什么；避免无休止闪烁。
- **刷新**：保留可用旧值，低调显示刷新进度。
- **空**：区分没有数据、筛选无结果、尚未配置和权限不足。
- **部分**：指出哪些数据缺失，避免把残缺结果表现成完整结论。
- **陈旧**：显示最后成功时间和影响；不能把旧数据伪装成当前数据。
- **错误**：说明后果、可恢复动作和仍可使用的内容。
- **正常**：不需要用绿色占满页面；安静的正常状态让异常更醒目。

状态变化要有可读文本，并在适当时通过语义化 live region 提供辅助技术可感知的更新。

## 7. 可访问性

- 使用语义化结构、正确标题顺序和有意义的页面标题。
- 所有操作可通过键盘完成，焦点清晰且顺序符合视觉流程。
- 正文、标签、图形和交互状态保持足够对比；不要只用颜色编码状态。
- 重要图形提供文字摘要、可访问表格或等价信息路径。
- 颜色、形状、标签和位置共同传达含义；色觉差异不应改变结论。
- 放大、文本重排和系统字体变化后仍可读取与操作。

## 8. 最终审视

完成前逐项回答：

1. 五秒内能否说出页面在回答什么？
2. 第一视觉锚点是否真的是最重要信号？
3. 去掉任何一个元素会不会更清楚？能去掉就去掉。
4. 单位、时间、范围、基线和新鲜度是否足以防止误读？
5. 加载、空、陈旧和错误状态是否与正常状态同样精致？
6. 键盘、窄屏、长文本和非理想数据是否可用？
7. 视觉是否安静但不单薄，现代但不炫技？
8. 实现是否仍然是自由源码，而不是对某个组件模板的复刻？
