# 可持续发展与 ESG 看板 Know-how

## 核心决定

帮助管理者和利益相关者判断影响、风险、机会、目标进展与数据可信度。IFRS 可持续披露强调面向投资者的决策有用和可比信息；内部运营看板也需保持边界与口径透明。

## 指标关系

- 排放：按组织/运营边界、范围、地点或市场口径、绝对量与强度展示；避免重复计算。
- 能源、水、废弃物：总量、强度、来源、回收与业务活动量共同解释。
- 目标：基准年、目标年、目标类型、当前路径和所需路径。
- 风险与机会：时间范围、暴露、财务影响和管理行动（有可靠数据时）。
- 社会与治理：人员、安全、供应链与治理指标必须有清楚定义，不拼成单一无意义总分。

## 可信度

标明报告边界、合并方法、因子版本、估算比例、第三方验证、重述和数据覆盖。强度下降可能与产量变化有关，绝对量可能仍上升。碳抵消、避免排放和实际减排不能混为一谈。

## 视觉气质

不必使用绿色、叶片和地球装饰。以可信、长期、材料感和清楚路径为主。目标路径、基准与差距应易读；地图仅在地域风险或资源分布有决策价值时使用。

## 状态

披露数据常有延迟和修订，明确期间、成熟度、估算和待验证状态。缺失不等于零，未覆盖实体不等于达标。

## 避免

不要做绿色洗白式大数字，不隐藏边界变化，不把不可比年份连成平滑趋势，不用综合 ESG 分数替代各主题证据。

## 质量门

边界、基准年、范围、单位、强度分母、目标路径、估算与验证状态是否足以复核？视觉是否服务证据而非环保装饰？
