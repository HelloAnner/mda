# 看板数据表达

先判断用户要理解的数据关系，再选择表现形式。示例只是候选，绝不是平台规定；可自由使用图形、表格、文本、地图、自定义 SVG、Canvas 或组合表达。

## 1. 识别关系

区分当前证据主要在表达什么：

- **当前状态**：现在是多少，是否正常，离目标多远。
- **时间变化**：趋势、季节性、拐点、事件前后和波动。
- **类别比较**：大小、排名、差距和贡献。
- **分布**：集中、离散、偏态、长尾和异常值。
- **组成**：部分与整体，且“整体”必须有稳定含义。
- **偏差**：相对目标、预算、基准、上期或控制范围。
- **相关**：两个或多个变量共同变化；不得暗示因果。
- **流动**：来源、去向、转化、库存或阶段损失。
- **空间**：位置确实影响结论，而不是只为使用地图。

同一数据可有多种好表达。根据比较精度、类别数量、标签长度、屏幕尺寸和交互目标选择，不要按字段类型机械选图。

## 2. 比较必须诚实

- 比较对象使用一致口径、单位、时区、周期和精度。
- 明确基线：目标、上期、同比、预算、基准群体或零点。
- 长度和面积编码要有诚实比例；截断坐标轴时必须让用户清楚。
- 双轴、面积、3D、透视和大小气泡容易制造错误关系，只有收益明确且能解释时使用。
- 排名要说明方向与并列；时间序列保持真实间隔；缺失时间不得无声连接。
- 不把累计值与期间值、总量与比率、名义值与实际值放在同一语义层级。

## 3. 上下文与标注

重要数据旁应能找到：

- 指标定义、单位和格式。
- 时间范围、粒度、时区和最近刷新时间。
- 筛选范围、样本、分母和排除规则。
- 比较基线和目标来源。
- 缺失、估算、修订、截断或采样说明。

标题应传达问题或结论，副标题补充统计范围。标签优先直接靠近数据，减少跨区域寻找图例。注释只解释真正影响理解的事件和异常。

## 4. 数字与精度

- 精度服务于决定，不展示数据系统偶然提供的小数位。
- 同类数字格式一致；不同量级可缩写，但单位必须清楚。
- 比率同时检查分子与分母；小样本的巨大百分比变化要谨慎。
- 货币说明币种与汇率口径；时长选用人能快速理解的单位。
- 正负、增长下降和“越大越好”不能仅靠颜色表达。
- `0`、空值、未知、不适用和未上报是不同状态，不得混为一谈。

## 5. 颜色语义

- 中性色承载结构，强调色承载注意力，状态色承载行动含义。
- 离散类别使用彼此可分辨的有限颜色；类别很多时优先标签、分组或交互，而不是扩展彩虹。
- 有序数值使用明度有序的连续色；有意义中心两侧的偏差才使用发散色。
- 红、橙、黄等告警色保持稀缺。正常状态不需要大片绿色。
- 颜色不是唯一通道；同时使用文字、形状、描边、位置或图案。
- 同一实体和状态在全页保持一致颜色，避免颜色含义漂移。

## 6. 表格与细节

表格适合精确查找、多字段扫描、异常处置和审计。做好：

- 有意义的默认排序和稳定列顺序。
- 数字按小数点或末位对齐，文本按阅读方向对齐。
- 单位、总计、分组、缺失值和选中状态明确。
- 大数据集提供搜索、筛选、分页或虚拟化，而不是把浏览器塞满。
- 条件格式只强调需要行动的少数值，不把每格变成彩色热图。

## 7. 不确定性与质量

- 样本量、置信区间、预测区间、误差范围或数据质量会影响决定时必须表现。
- 预测与历史使用明确不同的语义，并标出预测起点。
- 目标、估计、实际和修订值不能混为同一系列。
- 聚合可能隐藏群体差异；敏感决策应检查分段和绝对数量。
- 相关、同时发生和归因必须使用准确措辞，不把模式写成原因。

## 8. 质量门

确认：关系选择合理；比较口径一致；标题、单位、周期、基线和刷新清楚；颜色有语义且非唯一通道；数字精度恰当；缺失与不确定性没有被美化隐藏；重要图形有等价信息路径；没有因为追求“丰富”而堆叠不必要图表。
